# AgroVision

AgroVision is an AI-based Plant Disease Detection System developed using Deep Learning and Image Processing techniques. The system detects plant diseases from leaf images and provides accurate predictions along with treatment recommendations to help farmers improve crop health and reduce crop loss.

## Features

- Plant leaf disease detection using CNN
- Image upload and preprocessing
- Accurate disease classification
- Treatment and prevention suggestions
- User-friendly web interface
- Real-time prediction results
- Report generation support

## Technologies Used

- Python
- TensorFlow / Keras
- CNN (Convolutional Neural Network)
- Flask
- HTML, CSS, JavaScript
- OpenCV
- NumPy, Pandas

## Project Objectives

- Detect plant diseases accurately from leaf images
- Reduce manual inspection and human error
- Support early disease detection
- Improve agricultural productivity
- Assist farmers with quick diagnosis

## Workflow

1. Image Upload
2. Image Preprocessing
3. Feature Extraction
4. CNN Model Classification
5. Disease Prediction
6. Recommendation Generation
7. Result Display

## Future Enhancements
- Real-time camera-based detection
- Multi-language support


## Conclusion

AgroVision provides a smart and efficient solution for automatic plant disease detection using AI and deep learning technologies. The system helps farmers take timely action and supports sustainable agriculture practices.
